# 聊天过滤与自定义标签

Minecraft Java **1.21.1** 的纯客户端 NeoForge 模组。项目以 **NeoForge 21.1.235 / Java 21** 构建；配置只保存在本机，服务器及其他玩家不需要安装本模组。

## 项目简介

本模组提供三组独立功能：

- 按原文、整句或「刷 L」规则过滤或隐藏聊天。
- 为账号名或 UUID 设置聊天前后缀、名字颜色及本地名字标签。
- 为指定服务器地址配置聊天模板，使聊天栏中的插件昵称和称号也能正确匹配。

过滤规则不会修改发送到服务器的纯文本消息；前缀、后缀和名字颜色只用于本机聊天与本人头顶名牌的显示。

## 环境要求

- Minecraft Java **1.21.1**
- NeoForge **21.1.235** 或兼容的更新版本
- Java **21**
- 普通玩家使用时无需构建源码
- 开发构建时需允许 Gradle 下载 Minecraft/NeoForge 依赖

## 安装

1. 安装对应版本的 NeoForge。
2. 将构建产物放进目标 Minecraft 实例的 `mods` 目录。
3. 启动游戏。
4. 在 **模组** 列表中找到「聊天过滤与自定义标签」，打开 **配置**。

常规构建产物为 `build/libs/chatfilter_chattag-1.0.0.jar`。升级时替换旧 jar，配置不会随 jar 自动删除。

## 配置文件

配置保存在当前实例使用的 NeoForge 配置目录：

```text
config/chatfilter_chattag.json
```

- 第一次启动且文件不存在时使用内置默认规则。
- 草稿状态不会直接写入磁盘；只有在配置界面点击「保存」才会更新文件。
- 如果配置文件损坏、格式不受支持或超过读取大小限制，模组会保留原文件并禁止保存，直至修复或重新启动。
- 本模组不会通过网络上传规则、账号标签、UUID、服务器地址或屏蔽本。

## 功能

- **聊天词条**：一页并列出多条规则；每页容量随窗口尺寸和 GUI 缩放调整。可翻页、启停、编辑和调整优先级。每条发言只执行列表中第一条匹配的启用规则。
- **内置规则**：完整[词表](<chat-filter-wordlist.md>)随包分发，默认开启。较短、易误伤的缩写用整句匹配；较明确的短语用字面匹配。已有规则的动作、顺序和启用状态不会被新默认值覆盖。
- **玩家标签**：按真实游戏账号名或 UUID 设置前后缀和名字颜色。名字颜色填写原版色码（例如 `§6` 为金色）；留空或用 `§r` 保留原色。颜色只改识别到的名字，不改服务器称号、正文或前后缀自己的颜色。
- **本地样式**：标签可用 `§a` 等原版格式码，可点击输入框旁的插入按钮，或在支持的输入框按 `Ctrl+Shift+F8`。聊天和命令照常发送纯文本；只有能可靠关联的本人普通回显才在本机恢复着色。F5 自己的头顶名牌与聊天标签独立，使用服务端已同步的显示内容，并尊重隐藏规则。

> 默认只处理可识别的玩家发言，服务器发来的原版遮罩不会被解除。插件若用系统消息显示聊天，可为那个服务器单独启用下方的格式兼容；它不改变词条过滤、原版签名或向服务器发送的内容。

### 匹配与优先级

| 匹配模式 | 行为 |
|---|---|
| `L` 刷屏 | 只匹配由 `L/l`、空白或标点组成的整条正文 |
| 整句匹配 | 只在原始聊天正文完全相同时匹配 |
| 字面片段 | 在普通正文中查找字面文本，不使用正则表达式 |

词条按列表顺序执行；只要有一条启用规则命中，就只执行该规则，不继续检查后面的规则。重复的「匹配模式 + 匹配文本」不会通过屏蔽本重复导入。

可用动作：

| 动作 | 效果 |
|---|---|
| 替换 | 用指定纯文本替换每个命中片段，留空可删除 |
| 遮词 | 将命中片段替换为 `***` |
| 隐藏整条 | 隐藏整个聊天行 |

预览可通过配置页中的「试用原文」测试当前草稿。列表编辑不会改变已经发送到服务器的消息。

## 服务器格式

若自己的聊天前后缀单人有效、某服无效，先在「玩家标签」给自己的真实账号配置前后缀，再在「服务器格式」新增该服的**连接地址**和模板，点击保存。没有配置的服务器保持原样；不同地址或不同端口各有自己的规则。默认使用当前连接的登录账号名；如果聊天栏显示的是插件昵称，可为该服填入确切昵称。标签本身仍从你的账号或 UUID 配置读取。

按聊天栏的实际排版选择模板，分隔符和空格要一致：

| 聊天栏样式 | 模板 |
|---|---|
| `qaz: 你好` | `{name}: {message}` |
| `<qaz> 你好` | `<{name}> {message}` |
| `[会员] qaz: 你好` | `[会员] {name}: {message}` |
| `[会员] qaz: 你好`，且称号会变化 | `[{rank}] {name}: {message}` |

`{name}` 是发言人位置，`{message}` 必须在末尾；可选的 `{rank}` 放在 `{name}` 之前，并用字面字符分隔。以最后一条模板为例，`[会员] impro: qaz wsp` 和 `[会员] impro: qaz: wsp` 的发言人都是 `impro`，不会给它们加本人的标签。模板不匹配时原样显示。系统消息缺少原版发言人 UUID；如果插件公告或仿冒行与真实聊天格式一模一样，模板无法认证作者。

### 自动匹配当前服务器的昵称

在「服务器格式」填入目标账号名，点击「自动匹配」并保存。下次进入同一服务器后，模组会根据已经收到的 TAB 名字和聊天发言人位置收集候选，例如 `[EPIC] qaz`。选中要使用的候选并保存后才应用；只保存搜索目标不会自动更改昵称。没找到候选时，可以等该玩家发言之后再看，或继续手填昵称。

候选保留服务器称号供辨认。模板已把称号单独分在 `{rank}` 时，实际匹配的是 `{name}` 中的名字。这不会清掉 `[EPIC]`，也不会因为别人在正文里写 `qaz` 就给那个人加标签。自动发现不跨服务器或连接收集，也不向服务器请求额外数据。

## 添加屏蔽本

在**聊天词条**页点击**添加屏蔽本**，选择本机 UTF-8 Markdown 或 JSON 文件。规则加在列表末尾。同一匹配模式和文本的已有规则优先，重复条目不会覆盖已有开关或动作。导入先进入设置页的草稿，点击**保存**才写入当前客户端配置；关闭或取消可放弃草稿。

### Markdown

每行一条。普通列表项和 `[x]` 条目开启，`[ ]` 条目导入但关闭。需要保留特殊字符时可用反引号包住词条。

```markdown
# 我的屏蔽本

- 需要遮住的短语
- [x] `明确骚扰短语` — 隐藏整句
- [x] `不想看见的短语` — 替换为：***
- [ ] `先不启用的短语`
```

### JSON

用 `rules` 数组写条目。`PART` 按字面片段匹配，`WHOLE` 匹配整句。动作 `MASK` 为遮词，`HIDE` 隐藏整句，`REPLACE` 使用 `replacement`。这不是覆盖游戏配置的文件。

```json
{
  "rules": [
    {"pattern":"需要遮住的短语","match":"PART","action":"MASK","enabled":true},
    {"pattern":"某条固定消息","match":"WHOLE","action":"REPLACE","replacement":"替换后的文字","enabled":true}
  ]
}
```

导入只读取显式选中的本机文件，不执行文件内容。文件须为 UTF-8、不能超过 1 MiB；整张规则列表最多容纳 2048 条，每个匹配及替换文本最多 256 个 UTF-16 单元。不支持的格式、损坏或超限文件不会部分导入。

## 配置限制

| 项目 | 上限 |
|---|---:|
| 聊天规则 | 2048 条 |
| 玩家标签 | 128 条 |
| 服务器格式 | 64 条 |
| 匹配文本和替换文本 | 各 256 个 UTF-16 单元 |
| 前缀和后缀 | 各 96 个 UTF-16 单元 |
| 昵称槽位 | 64 个 UTF-16 单元 |
| 配置文件和屏蔽本 | 各 1 MiB |

服务器地址最多 260 个字符，聊天模板最多 256 个字符。模组不会保存重复账号或重复服务器地址。

## 常见问题

**配置界面提示读取失败**

原配置文件可能是旧格式、损坏或不符合当前安全限制。先从客户端日志确认具体错误；修复或恢复配置后重启游戏。本模组不会覆盖无法读取的原文件。

**标签没有出现在聊天栏**

确认玩家标签中的账号名或 UUID 与实际账号一致，并确认服务器聊天格式已匹配模板。系统消息、没有可靠作者信息的插件聊天以及原版遮罩可能不会被重新着色。

**过滤规则没有生效**

确认规则已启用、匹配模式正确且位于第一条命中的位置。整句匹配区分大小写；字面片段按原始可见文本匹配。默认规则不会覆盖保存后已有规则的开关、动作和顺序。

**服务器格式只对某个地址生效**

地址会规范化大小写和默认端口 `25565`，但不会查询 DNS 或合并其他端口或主机别名。请在同一实例中使用实际连接地址，并保留非默认端口。

## 开发构建

使用 JDK 21 和项目附带的 Gradle Wrapper。Windows（缓存齐全时可加 `--offline`）：

```powershell
.\gradlew.bat build '-Djava.io.tmpdir=C:\Temp' --no-daemon --max-workers=1
```

产物位于 `build/libs/`。资源包内默认词表是[内置资源](<src/main/resources/assets/chatfilter_chattag/default-wordlist.md>)；维护默认词条时，同步更新根目录[可编辑词表](<chat-filter-wordlist.md>)。本项目模组元数据声明 `All Rights Reserved`。

```text
├── assets/chatfilter_chattag/  # 界面语言和内置词表
├── META-INF/neoforge.mods.toml
└── chatfilter_chattag.mixins.json
```
